This will be a note-taking app to help people organize their thoughts, leave reminders for themselves, write down
information for later, etc. 
Planned features: 
-Create/edit/delete "notes", where users can input text and images
-Save what they've written so they can view it later
-Search their saved notes for specific words/phrases
-Optional account creation to allow viewing of notes across multiple devices
-Save note to device as a text file
